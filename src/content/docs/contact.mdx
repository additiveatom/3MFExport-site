## Communities

There's no official 3MF Export Plugin Discord as of yet. The 3MF
Export Plugin has its own **3mf-export** support channel under the
**plugins** heading within the HueForge Official Discord. You will
have received an email after purchasing
<a href="https://shop.thehueforge.com/products/hueforge?aff=3"><strong>HueForge</strong></a>
with a link inviting to the join the Discord.

## Feature requests

We're a one person team, so we prioritize ruthlessly:

1. **Bug fixes** — always first.
2. **New slicer support** — driven by user demand. If your slicer
   isn't on [our list](/getting-started/overview/#supported-slicers),
   tell us — we track requests.
3. **New printer profile support** — fastest path is to send us a 3MF
   you've sliced in the target slicer; we can usually add the bundled
   profile in a few hours.
4. **Quality-of-life UX** — slowest queue. Tell us anyway, it
   accumulates.

## Response times

Best-effort. Expect a reply within a couple business days. If something
is time-sensitive (e.g. a regression blocking a print you need to ship)
mark it in the subject line.
